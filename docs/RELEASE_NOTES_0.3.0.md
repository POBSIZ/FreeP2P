# FreeP2P 0.3.0 — 공유 코드 단축

친구에게 보내는 호스트 연결 코드와 참가 코드를 짧게 만들었습니다.
기본 표시 이름에서는 호스트 코드 123자, 참가 코드 79자입니다. 이름에 따라 길이는 달라집니다.
사용 방법은 같습니다. **코드 복사**를 눌러 보내고, 친구가 돌려준 코드도 등록하세요.
별도 가입이나 중계 서버는 필요하지 않습니다.

**함께할 사람 모두 0.3.0 이상으로 업데이트하세요.** 이전 앱은 `fpm2:`로 시작하는 새 코드를 읽지 못합니다.
새 버전은 예전의 `fpm1:` 코드도 읽을 수 있습니다. 업데이트한 뒤에는 새 코드를 서로 주고받으세요.
코드가 짧아져도 접속에 필요한 정보가 들어 있으므로 함께할 친구에게만 보내 주세요.

![호스트 연결 코드를 복사하는 화면](https://raw.githubusercontent.com/POBSIZ/FreeP2P/v0.3.0/docs/images/share-code.png)

사진 속 코드는 설명용 예시이며 실제 연결에 사용할 수 없습니다.

## 다운로드

- **Windows PC:** `FreeP2P-0.3.0-windows-x64.zip`을 받아 모두 압축을 푸세요.
  `FreeP2P` 폴더 안의 `FreeP2P.exe`를 실행합니다. 옆의 `_internal` 폴더도 함께 있어야 합니다.
- **Mac M 시리즈:** `FreeP2P-0.3.0-darwin-arm64.zip`을 받아 압축을 풀고 `FreeP2P` 앱을 여세요.

Python은 따로 설치하지 않아도 됩니다. `Source code`와 `.sha256` 파일은 실행할 때 필요하지 않습니다.
기존 앱에서 **앱 종료**를 누른 뒤 새 압축 파일을 다른 폴더에 풀어 실행하세요.
