# FreeP2P 0.1.0 — 첫 시험 배포

친구를 내 Minecraft Java 월드로 초대하는 프로그램입니다.
두 사람 모두 실행한 뒤 코드를 서로 주고받아 사용합니다. Python은 따로 설치하지 않아도 됩니다.

## 어떤 파일을 받으면 되나요?

- **Windows:** 아래 파일 목록에서 `FreeP2P-0.1.0-windows-x64.zip`을 받으세요.
  모두 압축을 푼 뒤 `FreeP2P` 폴더 안의 `FreeP2P.exe`를 실행합니다. `_internal` 폴더도 함께 있어야 합니다.
- **Mac M 시리즈:** `FreeP2P-0.1.0-darwin-arm64.zip`을 받아 압축을 풀고 `FreeP2P` 앱을 여세요.
  Intel Mac용은 아직 없습니다.

`Source code`는 개발자용 파일입니다. `.sha256`은 파일 확인용이므로 실행할 때 필요하지 않습니다.

## 사용 전에

처음 실행할 때 Windows나 Mac이 경고를 띄울 수 있습니다. 위의 경고 안내를 확인하세요.
인터넷 환경에 따라 연결되지 않을 수 있으며, 실제 Minecraft 월드 입장은 아직 검증하지 않았습니다.
연결 코드와 프로그램 로그는 공개하지 마세요.

Windows와 Mac에서 프로그램 사이의 데이터 전송 및 종료를 확인했습니다.
자세한 개발자용 기록은 [검증 범위](https://github.com/POBSIZ/FreeP2P/blob/main/TEST_RESULTS.md)를 참고하세요.
