# FreeP2P 0.1.0 — 첫 시험 배포

FreeP2P의 첫 시험 배포 버전입니다. 친구를 내 Minecraft Java Edition 월드로 초대할 때 사용합니다.
월드를 여는 사람과 참가할 친구 모두 프로그램을 실행하고 연결 코드를 서로 주고받으세요. Python은 따로 설치하지 않아도 됩니다.

## 어떤 파일을 받으면 되나요?

- **Windows:** 아래 파일 목록에서 `FreeP2P-0.1.0-windows-x64.zip`을 받으세요.
  모두 압축을 푼 뒤 `FreeP2P` 폴더 안의 `FreeP2P.exe`를 실행합니다. `_internal` 폴더도 함께 있어야 합니다.
- **Mac M 시리즈:** `FreeP2P-0.1.0-darwin-arm64.zip`을 받아 압축을 풀고 `FreeP2P` 앱을 여세요.
  Intel Mac용은 아직 없습니다.

프로그램을 실행하려면 위의 ZIP 파일을 받으세요. `Source code`는 개발자용 소스이며 `.sha256`은 다운로드한 파일을 확인할 때 씁니다.

## 사용 전에

처음 실행할 때 Windows나 Mac이 경고를 표시하면 [실행 경고 안내](https://github.com/POBSIZ/FreeP2P/blob/v0.1.0/docs/SECURITY_WARNINGS.md)를 확인하세요.
인터넷 환경에 따라 연결되지 않을 수 있습니다. 이 버전에서 실제 Minecraft 월드 입장은 검증하지 않았습니다.
연결 코드와 프로그램 로그는 공개하지 마세요.

Windows와 Mac에서 프로그램 간 데이터 전송과 종료를 확인했습니다.
이후 버전의 결과를 포함한 개발자용 기록은 [검증 범위](https://github.com/POBSIZ/FreeP2P/blob/main/TEST_RESULTS.md)를 참고하세요.
