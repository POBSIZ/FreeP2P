FreeP2P — 친구와 Minecraft Java 함께하기

함께할 사람 모두 자기 컴퓨터에서 FreeP2P를 실행하세요. Python은 설치하지 않아도 됩니다.
짧아진 새 코드를 쓰려면 함께할 사람 모두 FreeP2P 0.4.0 이상으로 업데이트하세요.
이전 버전 앱은 새 코드를 읽지 못합니다. 업데이트 후 코드를 새로 주고받으세요.
Windows: 받은 파일을 모두 압축 풀기 → FreeP2P 폴더 → FreeP2P.exe
Mac M 시리즈: 받은 압축 파일을 두 번 클릭 → FreeP2P 앱
Windows의 _internal 폴더는 지우거나 실행 파일과 따로 옮기지 마세요.

월드를 여는 사람:
1. 게임에서 Esc → LAN 서버 열기 → LAN 월드 시작을 누르고 표시된 숫자를 확인합니다.
2. FreeP2P의 ‘내 월드 열기’에서 ‘게임에서 표시된 LAN 포트’에 그 숫자를 입력하고 ‘호스트 시작’을 누릅니다.
3. ‘코드 복사’를 눌러 친구와의 개인 대화창에 붙여넣어 보냅니다.
4. 친구가 돌려준 코드를 ‘참가 코드 등록’에 붙여넣고 ‘참가자 추가 +’를 누릅니다.
화면 위 ‘지금 할 일’에서 다음 순서를 확인할 수 있습니다.

들어갈 친구:
1. 친구 월드 참가 → 받은 코드 붙여넣기 → 참가 준비.
2. 내 참가 코드를 복사해 월드를 연 친구에게 보냅니다.
3. 연결됨이 나오면 게임 접속 주소 복사를 누릅니다.
4. Minecraft 멀티플레이 → 직접 연결 → 복사한 주소 붙여넣기.
접속 설정은 보통 바꾸지 않아도 됩니다.

화면을 보며 따라 하기:
https://github.com/POBSIZ/FreeP2P/blob/main/docs/USER_GUIDE.md
실행을 막는 경고가 나오면:
https://github.com/POBSIZ/FreeP2P/blob/main/docs/SECURITY_WARNINGS.md

다 놀았으면 FreeP2P 화면의 앱 종료를 누르고 확인하세요. 브라우저 탭만 닫으면 FreeP2P는 계속 켜져 있습니다.
다른 월드로 바꾸려면 연결 끝내기를 누르고 처음부터 준비하세요.
코드는 함께할 친구에게만 보내 주세요.
인터넷 환경에 따라 연결되지 않을 수 있습니다. 아직 시험 배포 중이며 실제 Minecraft 월드 입장은 아직 검증하지 않았습니다.
