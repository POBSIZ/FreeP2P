FreeP2P 0.1.0 — Minecraft Java LAN

Python 설치 없이 실행할 수 있습니다.
Windows: ZIP 전체 압축 해제 후 FreeP2P.exe 실행 (_internal 폴더 필수)
Mac M 시리즈: ZIP 압축 해제 후 FreeP2P.app 실행

그림과 함께 보는 사용법:
https://github.com/POBSIZ/FreeP2P/blob/main/docs/USER_GUIDE.md
보안 경고/실행 차단 안내:
https://github.com/POBSIZ/FreeP2P/blob/main/docs/SECURITY_WARNINGS.md

호스트: 게임에서 LAN 열기 → 실제 LAN 포트 입력 → 호스트 코드 전달
친구: 호스트 코드 입력 → 참가 준비 → 내 참가 코드를 호스트에게 전달
호스트: 친구의 참가 코드 등록
친구: 연결됨 확인 → Minecraft 직접 연결에 화면의 127.0.0.1:포트 입력

탭만 닫으면 연결은 유지됩니다. 완전히 종료하려면 웹의 앱 종료를 누르세요.
연결 코드와 웹 제어 주소/토큰, 원시 로그는 공개하지 마세요.
모든 NAT에서 연결되지는 않으며 실제 게임 플레이 검증은 아직 남아 있습니다.
현재 배포본은 Windows 인증서 서명 및 Apple Developer ID 서명/공증을 하지 않았습니다.
