# FreeP2P 0.2.0 — 코드 교환 안내 개선

연결 코드를 주고받을 순서와 연결 실패 시 확인할 내용을 화면에 표시하도록 바꿨습니다. 사용 설명서도 새 화면에 맞췄습니다.

- 화면 위의 **지금 할 일**에서 코드를 보낼 차례인지, 친구 코드를 등록할 차례인지 알려 줍니다.
- 참가 인원과 접속 포트는 필요할 때 설정을 펼쳐 바꿀 수 있습니다.
- 연결에 실패하면 확인할 내용과 **다시 연결** 버튼을 보여 줍니다.
- 코드 복사 안내, 게임 응답 확인, 친구 연결 해제 확인창을 개선했습니다.
- 화면이 자동으로 갱신돼도 키보드 초점을 유지하며, 작은 화면에서도 조작할 수 있습니다.

![새 연결 안내 화면](https://raw.githubusercontent.com/POBSIZ/FreeP2P/v0.2.0/docs/images/next-step.png)

사진 속 이름과 코드는 설명용 예시입니다. 사진 속 코드로는 연결할 수 없습니다.

## 다운로드

- **Windows PC:** `FreeP2P-0.2.0-windows-x64.zip`을 받아 모두 압축을 푸세요.
  `FreeP2P` 폴더 안의 `FreeP2P.exe`를 실행합니다. 옆의 `_internal` 폴더도 함께 있어야 합니다.
- **Mac M 시리즈:** `FreeP2P-0.2.0-darwin-arm64.zip`을 받아 압축을 풀고 `FreeP2P` 앱을 여세요.

Python은 따로 설치하지 않아도 됩니다. 프로그램을 실행하려면 위의 ZIP 파일을 받으세요.
`Source code`는 개발자용 소스이며 `.sha256`은 다운로드한 파일을 확인할 때 씁니다.
기존 버전을 사용 중이면 먼저 **앱 종료**를 누르고, 새 버전을 별도 폴더에 풀어 실행하세요.
다시 시작한 뒤에는 친구와 새 코드를 주고받으세요.

인터넷 환경에 따라 연결되지 않을 수 있습니다.
