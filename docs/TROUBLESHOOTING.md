# 문제 해결

[사용 가이드](USER_GUIDE.md) · [보안 경고 그림 안내](SECURITY_WARNINGS.md)

| 증상 | 확인할 것 |
| --- | --- |
| Windows 실행 실패 | 실행용 ZIP 전체를 풀었는지, `_internal`이 함께 있는지 확인합니다. 격리됐다면 보안 안내를 읽으세요. |
| Mac 앱이 열리지 않음 | M 시리즈용인지 확인합니다. Intel용은 제공하지 않습니다. 개발자 확인 경고는 보안 안내를 읽으세요. |
| 브라우저 탭을 닫아 버림 | 실행 파일을 다시 열면 기존 앱의 화면이 열립니다. |
| ‘실행 링크로 열어 주세요’ | 저장한 웹 주소는 실행 토큰이 없거나 오래됐을 수 있습니다. 실행 파일을 다시 엽니다. |
| ‘주소 확인 실패’ | UDP/STUN이 차단되거나 STUN 서비스가 응답하지 않을 수 있습니다. 신뢰하는 다른 네트워크에서 확인하세요. |
| 연결 시도 후 실패 | **양쪽 코드**가 최신이고 등록됐는지 확인합니다. 재시도해도 안 되면 NAT/방화벽 조합이 지원되지 않을 수 있습니다. |
| 같은 공유기에서도 실패 | NAT hairpin 미지원일 수 있습니다. 공인 주소를 통한 성공을 보장하지 않습니다. |
| 연결됨인데 게임 접속 실패 | 호스트 LAN 월드가 열려 있는지와 LAN 포트를 확인합니다. 게임 버전·계정·모드를 맞추세요. |
| 접속 주소가 헷갈림 | **참가자 화면의 게임 접속 주소**를 Minecraft 직접 연결에 입력합니다. 호스트 IP·웹 URL·코드는 게임 주소가 아닙니다. |
| 포트를 열 수 없음 | 참가 포트를 다른 프로그램이 사용 중이면 `25566` 등 다른 포트를 선택합니다. |
| 인원 변경 실패 | 현재 등록 인원 이상으로 설정합니다. 필요 없는 참가자를 해제한 뒤 변경하세요. |
| 재시작/네트워크 변경 후 연결 불가 | 양쪽 세션을 다시 만들고 새 코드를 교환하세요. |
| 앱 종료 후 페이지가 남음 | 정상입니다. 종료 안내를 확인하고 탭을 닫으면 됩니다. |

## 오류 보고 전에

릴리스 버전, OS 버전과 CPU 종류, 호스트/참가자 여부, 발생 단계, 오류 문구를 적어 주세요.
실제 Minecraft 월드 입장과 단순 FreeP2P 연결 상태를 구분해 주세요.
**공개 이슈에 연결 코드·웹 제어 URL·IP·원시 로그를 붙이지 마세요.**
캡처의 코드 입력란, 주소, 이름, 최근 활동 중 민감한 정보를 가려 주세요.

## 로컬 진단 파일

- Windows: `%LOCALAPPDATA%\FreeP2P\app.log`
- macOS: `~/Library/Application Support/FreeP2P/app.log`

같은 폴더의 `instance.json`에는 웹 제어 토큰이 들어 있습니다.
로그에도 로컬 제어 주소가 기록되므로 파일 전체를 공개하지 말고 비밀이 없는 오류 문구만 발췌하세요.
검증 범위와 아직 확인하지 않은 내용은 [TEST_RESULTS.md](../TEST_RESULTS.md)를 참고하세요.
