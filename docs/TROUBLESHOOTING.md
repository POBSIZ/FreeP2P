# 잘 안 될 때

[사용법](USER_GUIDE.md) · [실행 경고 안내](SECURITY_WARNINGS.md)

자기 상황과 같은 제목부터 읽어 보세요.

## 프로그램이 안 열려요

Windows에서는 받은 압축 파일을 먼저 **모두 압축 풀기**로 풀어 주세요.
`FreeP2P.exe`와 `_internal` 폴더가 같이 있어야 합니다. 실행 파일만 바탕 화면으로 옮겼다면 원래 폴더에서 다시 실행하세요.

Mac용은 M 시리즈 Mac 전용입니다. **Apple → 이 Mac에 관하여**에 Intel이라고 나오면 이 버전은 사용할 수 없습니다.
실행을 막는 경고가 보이면 [경고창 안내](SECURITY_WARNINGS.md)를 확인하세요.

## 화면을 닫았는데 다시 어디서 여나요?

FreeP2P 실행 파일을 다시 여세요. 켜져 있던 프로그램의 화면이 다시 나타납니다.
‘실행 링크로 열어 주세요’라고 나올 때도 같은 방법으로 여세요. 예전에 저장해 둔 브라우저 주소는 쓰지 않는 편이 좋습니다.

## 코드가 안 나오고 ‘코드 준비 실패’라고 떠요

우선 인터넷이 연결되어 있는지 확인해 주세요. 프로그램이 자동으로 다시 시도합니다.
잠시 기다려도 그대로라면 **연결 끝내기**를 누르고 다시 시작해 보세요.
회사·학교·공용 인터넷에서는 프로그램의 통신이 막혀 있을 수 있습니다.
가능하면 집 인터넷 등 다른 환경에서 시도해 보세요. 보안 프로그램을 무작정 끄지는 마세요.

## 코드까지 넣었는데 ‘연결됨’이 안 나와요

둘이 같이 아래 순서대로 확인해 주세요.

1. 두 사람 모두 FreeP2P가 켜져 있나요?
2. 월드를 연 사람이 **호스트 연결 코드**를 친구에게 보냈나요?
3. 들어갈 친구도 **내 참가 코드**를 돌려보냈나요?
4. 월드를 연 사람이 돌아온 코드를 넣고 **참가자 추가 +**까지 눌렀나요?

네 가지를 모두 했다면 **다시 연결** 버튼이 있을 때 눌러 보세요.
그래도 안 되면 두 사람 모두 **연결 끝내기** 후 다시 시작해 새 코드를 주고받아 보세요.
예전에 복사한 코드가 아니라 지금 화면에 있는 코드를 사용해야 합니다.

인터넷이나 공유기 환경에 따라 이 방법으로 연결할 수 없는 경우도 있습니다.
같은 집 인터넷이라고 반드시 연결되는 것도 아닙니다. 위 순서로 해도 안 된다면 설정을 계속 바꾸기보다 다른 인터넷 환경에서 확인해 주세요.

## 받은 코드를 읽을 수 없다고 나와요

`fpm2:`로 시작하는 짧은 코드는 FreeP2P 0.3.0 이상에서 사용할 수 있습니다.
함께할 사람 모두 [새 버전](https://github.com/POBSIZ/FreeP2P/releases/tag/v0.3.0)을 받아 실행한 뒤 코드를 새로 주고받으세요.
코드를 직접 고치거나 `fpm2:` 부분을 지우지 말고 **코드 복사**로 전체를 보내 주세요.
새 버전은 예전의 `fpm1:` 코드도 읽을 수 있지만, 예전 앱은 새 코드를 읽지 못합니다.

## FreeP2P는 ‘연결됨’인데 게임에 못 들어가요

**월드를 연 사람**이 확인할 것:

- Minecraft 월드가 아직 열려 있나요?
- **LAN 서버 열기**를 했나요?
- 게임이 알려 준 숫자와 FreeP2P에 입력한 **LAN 포트**가 같은가요?

FreeP2P의 **내 게임 열림 확인**을 누르면 게임이 응답하는지 확인할 수 있습니다. 결과는 버튼 아래에 나옵니다.
응답이 없다고 나오면 게임에서 LAN 서버를 열었는지, 표시된 숫자를 제대로 적었는지 먼저 확인하세요.

![내 게임 열림 확인 버튼 아래에 표시되는 확인 결과 예시](images/game-check.png)

월드를 다시 열었다면 그 숫자가 바뀌었을 수 있습니다. 이때는 FreeP2P도 **연결 끝내기** 후 새 숫자로 시작하고 코드를 다시 교환하세요.

**들어갈 친구**가 확인할 것:

- FreeP2P의 **게임 접속 주소 복사**를 눌렀나요?
- Minecraft **멀티플레이 → 직접 연결**의 서버 주소 칸에 붙여넣었나요?
- 메신저에서 받은 연결 코드나 브라우저 주소를 넣지는 않았나요?

둘이 사용하는 게임 버전과 필요한 모드도 맞아야 합니다. 게임에서 로그인 관련 오류가 나오면 그 안내도 확인해 주세요.
**내 게임 열림 확인**에 성공해도 실제 게임 입장까지 확인된 것은 아닙니다.

## ‘포트를 열 수 없습니다’라고 떠요

다른 프로그램이 같은 번호를 쓰고 있을 수 있습니다.
**친구 월드 참가** 화면에서 **접속 설정**을 펼치세요.
**이 PC의 게임 접속 포트**를 `25565`에서 `25566`으로 바꿔 다시 준비해 보세요.
연결 후에는 게임 주소를 직접 외워 넣지 말고 **게임 접속 주소 복사**로 새 주소를 복사하세요.

![접속 설정을 펼쳐 이 PC의 게임 접속 포트를 바꾸는 위치](images/guest-options.png)

## 인원을 줄일 수 없어요

이미 등록한 친구 수보다 작게 설정할 수는 없습니다.
참가자 목록에서 필요 없는 친구의 **연결 해제**를 누르고 확인하세요.
그다음 **참가 코드 등록 → 최대 참가자 수 변경**을 펼쳐 숫자를 줄여 보세요.

## ‘프로그램의 응답을 기다리고 있어요’라고 떠요

지금 보이는 상태는 마지막으로 확인한 내용이라 실제 연결 상태와 다를 수 있습니다.
FreeP2P 실행 파일이 켜져 있는지 확인하고 **다시 확인**을 누르세요.
앱을 이미 종료했다면 실행 파일을 다시 열어 주세요. 새로 시작했다면 친구와 코드도 다시 주고받아야 합니다.

## 여전히 안 되면 알려 주세요

[문제 신고하기](https://github.com/POBSIZ/FreeP2P/issues/new?template=bug_report.md)에서 다음 내용을 적어 주세요.

- Windows인지 Mac인지, 사용 중인 FreeP2P 버전
- 월드를 여는 쪽인지 들어가는 쪽인지
- 어느 버튼을 누른 뒤 문제가 생겼는지
- 화면이나 게임에 나온 오류 문구

화면을 첨부한다면 **연결 코드, 브라우저 주소, 개인 이름은 가려 주세요.**
프로그램이 기록한 로그 파일도 통째로 올리지 마세요. 친구에게만 알려 줘야 할 정보가 들어 있을 수 있습니다.

<details>
<summary>진단 파일 위치가 필요한 경우</summary>

- Windows: `%LOCALAPPDATA%\FreeP2P\app.log`
- Mac: `~/Library/Application Support/FreeP2P/app.log`

오류 부분만 골라서 확인하세요. 같은 폴더의 `instance.json`이나 로그 전체는 공개하지 마세요.

</details>
