# 실행하려는데 경고가 뜨나요?

[사용법으로 돌아가기](USER_GUIDE.md) · [파일 받기](https://github.com/POBSIZ/FreeP2P/releases/tag/v0.1.0)

FreeP2P는 아직 Windows와 Apple의 개발자 확인 절차를 거치지 않아 처음 열 때 경고가 나올 수 있습니다.
**이 저장소에서 직접 받은 파일인지 먼저 확인하세요.** 모르는 사람이 따로 보낸 파일이라면 아래 다운로드 페이지에서 다시 받는 편이 좋습니다.

[FreeP2P 다운로드 페이지](https://github.com/POBSIZ/FreeP2P/releases/tag/v0.1.0)

아래 그림은 순서를 설명하기 위해 만든 안내 그림입니다. 실제 경고창과 생김새나 문구가 조금 다를 수 있습니다.

## Windows에서 ‘Windows의 PC 보호’가 나올 때

1. 경고창의 **추가 정보**를 누릅니다.
2. 앱 이름이 `FreeP2P.exe`인지 확인합니다. 게시자는 ‘알 수 없는 게시자’로 표시될 수 있습니다.
3. 직접 받은 파일이 맞고 실행하기로 했다면 **실행**을 누릅니다.

![Windows 경고창에서 추가 정보와 실행을 누르는 순서](images/windows-warning.png)

**‘실행’ 버튼이 없나요?** 컴퓨터의 보안 설정이나 회사·학교의 사용 제한 때문일 수 있습니다.
관리하는 사람이 있다면 문의해 주세요. 이 프로그램을 열기 위해 컴퓨터의 보안 기능을 통째로 끄지는 마세요.

**‘바이러스’나 ‘위협이 발견됨’이라고 나오나요?** 위 경고와 다른 경우입니다.
억지로 실행하거나 차단된 파일을 복원하지 말고, 경고 문구를 [문제 신고](https://github.com/POBSIZ/FreeP2P/issues)에 남겨 주세요.

## Mac에서 개발자를 확인할 수 없다고 나올 때

1. `FreeP2P` 앱을 한 번 열어 보고 경고를 확인합니다.
2. 화면 왼쪽 위 **Apple → 시스템 설정 → 개인정보 보호 및 보안**으로 들어갑니다.
3. 아래로 내려 FreeP2P가 차단되었다는 안내를 찾습니다.
4. **그래도 열기**를 누릅니다. 버전에 따라 **확인 없이 열기**로 표시될 수 있습니다.
5. 앱 이름을 확인하고, Mac에서 암호나 지문 확인을 요청하면 진행합니다.

![Mac 설정에서 FreeP2P를 허용하는 순서](images/mac-warning.png)

허용 버튼이 없거나 회사·학교 컴퓨터라면 관리자에게 문의하세요.
**‘컴퓨터를 손상시킵니다’ 또는 ‘앱이 손상되었습니다’**라고 나오면 위 단계를 그대로 따라 하지 마세요.
공식 다운로드 페이지에서 다시 받아 보고, 같은 문제가 생기면 정확한 경고 문구를 알려 주세요.

## 네트워크 사용을 허용할지 물어볼 때

FreeP2P가 친구의 컴퓨터와 통신해도 되는지 묻는 별도의 창입니다.
프로그램 이름과 위치가 방금 실행한 FreeP2P인지 확인하세요. 집처럼 신뢰하는 네트워크에서 사용할 때 필요한 통신만 허용하면 됩니다.
회사·학교 컴퓨터에서는 관리자에게 확인하세요. 방화벽 전체를 끌 필요는 없습니다.

<details>
<summary>받은 파일이 같은 파일인지 직접 확인하고 싶다면 (선택)</summary>

평소 사용에는 아래 명령을 입력할 필요가 없습니다.
다운로드 페이지의 `.sha256` 파일은 압축 파일이 바뀌었는지 비교할 때 쓰는 확인용 파일입니다.

압축 파일이 있는 폴더에서 Windows PowerShell은 다음 명령을 사용합니다.

```powershell
Get-FileHash -Algorithm SHA256 .\FreeP2P-0.1.0-windows-x64.zip
```

Mac 터미널에서는 다음 명령을 사용합니다.

```bash
shasum -a 256 FreeP2P-0.1.0-darwin-arm64.zip
```

나온 문자열이 같은 이름의 `.sha256` 파일 내용과 일치해야 합니다.
이 검사는 파일이 같은지 확인할 뿐, 프로그램이 안전하다는 보증은 아닙니다.

</details>
