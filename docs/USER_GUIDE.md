# FreeP2P 사용 가이드

[처음으로](../README.md) · [다운로드](https://github.com/POBSIZ/FreeP2P/releases) · [실행 차단 안내](SECURITY_WARNINGS.md) · [문제 해결](TROUBLESHOOTING.md)

앱 화면은 **실제 UI에 가상 데이터를 표시한 캡처**입니다. 예시 코드는 연결되지 않습니다.
게임 메뉴와 운영체제 안내 그림은 실제 스크린샷이 아닌 **설명용 도식**입니다.

## 1. 두 PC에 준비하기

호스트와 친구 모두 Minecraft **Java Edition**, 웹 브라우저, 각자 운영체제에 맞는 FreeP2P가 필요합니다.
게임 버전과 필요한 모드·모드 로더 구성을 맞추세요. 게임의 계정 인증 조건도 그대로 적용됩니다.

1. [Releases](https://github.com/POBSIZ/FreeP2P/releases)에서 `Assets`를 펼칩니다.
2. Windows는 `windows-x64.zip`, M 시리즈 Mac은 `darwin-arm64.zip`을 받습니다.
3. **Source code (zip)**은 개발자용 소스입니다. 실행용 ZIP과 혼동하지 마세요.
4. ZIP을 완전히 풀고 실행합니다. Windows의 exe 옆 `_internal` 폴더는 필수입니다.
5. 브라우저가 열리면 준비 완료입니다. OS에서 막히면 [앱별 허용 절차](SECURITY_WARNINGS.md)를 확인하세요.

![ZIP 선택부터 브라우저 열기까지](images/download.png)

Python이나 다른 런타임을 설치할 필요가 없습니다. 앱 자체는 관리자 권한을 요구하지 않습니다.
방화벽 통신 허용이나 OS 최초 실행 확인은 별도로 표시될 수 있습니다.

## 2. 호스트: Minecraft에서 LAN 월드 열기

1. Minecraft의 싱글플레이 월드에 들어갑니다.
2. **Esc → LAN 서버 열기 → LAN 월드 시작**을 진행합니다. 메뉴 이름은 버전에 따라 조금 다릅니다.
3. 게임에 표시된 **LAN 포트 숫자**를 기록합니다. 예: `51234`.
4. FreeP2P를 실행하는 동안 월드도 계속 열어 둡니다.

![Minecraft LAN 메뉴와 포트 확인 경로 도식](images/minecraft-lan.png)

게임이 포트 입력란을 제공한다면 사용 가능한 포트를 지정할 수 있습니다.
어떤 경우든 **게임이 실제로 연 포트**를 다음 단계에 입력하세요. 그림의 `51234`를 그대로 넣는 것이 아닙니다.

## 3. 호스트: FreeP2P 시작

1. **내 월드 열기**를 선택합니다.
2. 표시 이름과 **게임에서 표시된 LAN 포트**를 입력합니다.
3. **최대 참가자 수**를 정합니다. 호스트를 제외한 등록 가능한 참가자 수이며 기본값은 16명입니다.
4. **호스트 시작**을 누릅니다.

![호스트 이름, LAN 포트 예시, 최대 참가자 수와 시작 버튼](images/host-setup.png)

게임 포트, FreeP2P의 UDP 포트, 웹 화면의 포트는 서로 다른 용도입니다.
인터넷 주소를 확인한 뒤 연결 코드가 표시될 때까지 잠시 기다리세요.

## 4. 호스트 연결 코드를 친구에게 보내기

**호스트 연결 코드 → 코드 복사**를 누르고 신뢰할 수 있는 개인 메신저 등으로 전달합니다.
`fpm1:`부터 끝까지 모두 전달해야 합니다. 화면의 웹 주소를 보내는 것이 아닙니다.

![연결 코드 위치와 코드 복사 버튼 — 연결 불가 예시](images/share-code.png)

연결 코드에는 외부 주소와 접속 인증 정보가 들어 있습니다. 공개 채팅방·GitHub 이슈·방송에 노출하지 마세요.
이 문서 이미지의 예시 코드는 사용할 수 없습니다.

## 5. 친구: 참가 준비 후 내 코드를 돌려주기

1. 자기 PC에서 FreeP2P를 실행하고 **친구 월드 참가**를 선택합니다.
2. 표시 이름을 입력합니다. **이 PC의 게임 접속 포트**는 보통 `25565`를 유지합니다.
3. 호스트에게 받은 전체 코드를 **호스트 연결 코드**에 붙여넣습니다.
4. **참가 준비**를 누릅니다.
5. 다음 화면의 **내 참가 코드 → 코드 복사**로 코드를 복사하여 호스트에게 돌려줍니다.

![참가자 설정과 호스트 코드 입력 위치](images/guest-setup.png)

참가 포트는 친구 PC에서 Minecraft가 접속할 포트입니다. **호스트의 LAN 포트와 같을 필요가 없습니다.**
이미 다른 프로그램이 `25565`를 사용하면 `25566` 등 다른 사용 가능한 포트로 바꾸세요.

## 6. 호스트: 친구의 참가 코드 등록

호스트 화면의 **참가 코드 등록** 입력란에 친구가 보내 준 코드를 붙여넣고 **참가자 추가 +**를 누릅니다.
친구가 여러 명이면 각각 반복합니다. 호스트 코드만 전달하고 이 단계를 생략하면 연결되지 않습니다.

![참가 코드 추가와 최대 참가자 수 변경 위치](images/register-peer.png)

운영 중 인원 제한은 **최대 참가자 수 → 적용**으로 바꿉니다.
이미 등록된 인원보다 작게 내리려면 먼저 해당 참가자의 **연결 해제**를 누르세요.
한도를 늘려도 Minecraft의 자체 최대 인원이나 호스트 PC 성능 제한이 바뀌지는 않습니다.

## 7. 친구: 연결됨 확인 후 Minecraft 접속

양쪽 코드가 등록되면 홀 펀칭과 암호화 연결을 자동으로 시도합니다.
참가자 화면에서 **직접 연결됨 / 호스트 연결: 연결됨**을 확인하세요.

![참가자 연결 완료 상태와 로컬 게임 접속 주소](images/guest-connected.png)

1. **게임 접속 주소 복사**를 누릅니다.
2. Minecraft **멀티플레이 → 직접 연결**을 엽니다.
3. 복사한 주소(기본 `127.0.0.1:25565`)를 입력하고 접속합니다.

![Minecraft 직접 연결에 로컬 주소를 입력하는 경로 도식](images/minecraft-join.png)

호스트의 공인 IP, 웹 주소, `fpm1:` 코드를 Minecraft에 넣지 마세요.
참가 포트를 변경했다면 앱에 표시되는 바뀐 주소를 사용하세요.
LAN 서버 목록에 자동으로 나타나는 기능은 지원하지 않습니다.

## 8. 종료·다시 열기·업데이트

| 동작 | 결과 |
| --- | --- |
| 브라우저 탭 닫기 | FreeP2P와 연결이 계속 동작합니다. |
| 실행 파일 다시 열기 | 이미 실행 중인 앱의 웹 화면을 다시 엽니다. |
| 세션 종료 | 해당 세션의 모든 터널 연결을 끊습니다. 웹에서 새 세션을 만들 수 있습니다. |
| 웹 상단 앱 종료 → 확인 | FreeP2P와 모든 터널 연결을 종료합니다. Minecraft 월드를 직접 종료하지는 않습니다. |
| 호스트 월드 닫기 / PC 절전 | 친구가 게임을 계속할 수 없습니다. |

![앱을 완전히 종료하는 확인창](images/quit.png)

업데이트는 **앱 종료** 후 새 ZIP을 다른 폴더에 완전히 풀어 사용하세요. 구버전 파일과 섞지 마세요.
자동 업데이트 기능은 없습니다. 재시작하면 양쪽에서 새 코드를 교환해야 합니다.
삭제할 때도 앱을 종료한 뒤 배포 폴더 또는 `.app`을 삭제합니다.

## 9. 주의점

- 목적지에 따라 매핑을 바꾸는 NAT나 UDP 차단 등에서는 연결되지 않을 수 있습니다.
  CGNAT라는 이유만으로 항상 실패하는 것은 아니며 공유기 조합과 정책에 따라 달라집니다.
- 같은 공유기에서 공인 주소로 연결하는 경우 NAT hairpin 지원 여부도 영향을 줍니다.
- STUN은 외부 주소 확인에 사용합니다. 기본 후보는 Cloudflare와 Google이며 서비스 가용성을 보장하지 않습니다.
- 앱은 VPN 설치, 방화벽 전체 해제, 자동 포트 포워딩을 수행하지 않습니다.
- 등록한 친구는 호스트의 지정된 로컬 게임 포트에 접속할 수 있습니다. 모르는 사람을 등록하지 마세요.
- 호스트 LAN 포트 또는 네트워크가 바뀌면 세션을 다시 설정하고 새 코드를 교환하세요.
- **LAN 포트 확인**은 TCP 응답만 검사합니다. 게임 버전·모드·로그인이나 월드 입장을 보장하지 않습니다.
- 전송 계층 검증은 통과했지만 실제 Minecraft 월드 입장까지 검증된 정식 버전은 아닙니다.

문제가 있으면 [문제 해결](TROUBLESHOOTING.md)을 읽고 비밀을 지운 재현 정보만 이슈에 남겨 주세요.
